🎯 The Problem

  • Utility companies publish disruption notices on scattered websites
  • Unstructured formats — PDFs, long text, inconsistent data
  • No single source of truth for citizens
  • Hard to know if your neighborhood is affected

💡 Our Solution

  • Automated collection from 9+ data sources
  • AI-powered text processing and location extraction
  • Interactive map with push notifications
  • Installable as a Progressive Web App

⚙️ Data Pipeline

🕷️ Crawlers → ✂️ Filter & Split → 🏷️ Categorize → 📍 Extract Locations → 🗺️ Geocode → 🔗 Event Match → 🔔 Notify

  • Precomputed GeoJSON crawlers skip all AI stages
  • 3-stage Gemini LLM processing for unstructured text
  • Multi-service geocoding: Google, Overpass (OSM), Cadastre
  • Event matching groups messages into real-world incidents

📖 Key Concepts

  • Source — a crawled document from a utility website
  • Message — an individual disruption notice (1 source → N messages)
  • Event — a real-world incident grouping related messages
  • Interest — a user-defined map zone for notifications
  • GeoJSON — geographic data format (points, polygons)
  • Categories — disruption types (water, heating, roads, …)
  • Embedding — 768-dim vector for text similarity matching

🔗 Event Matching

  • Groups messages into real-world incidents
  • Composite score from 4 signals:
Location
Geographic proximity
Time
Temporal overlap
Text
Embedding cosine similarity
Category
Disruption type matching

  • ≥ 0.70 → auto-attach to event
  • 0.55 – 0.70 → LLM verification (Gemini)
  • < 0.55 → create new event
